# GS8 Triple 2.0

Проект для GAC GS8 Gen2 на Android 9.

## Что делает эта сборка
- Выбор двух или трёх приложений.
- Запуск выбранных приложений в Freeform с рассчитанными соседними границами.
- Получение фактического размера дисплея вместо жёстко заданных 1920×968.
- Масштабирование сохранённых ширин при изменении разрешения.
- Компактная плавающая кнопка GS8: её можно перетаскивать, короткое нажатие открывает меню приложения.

## Ограничения Android 9
- `ActivityOptions.launchBounds` — это запрос оконному менеджеру. Прошивка и сами приложения могут его проигнорировать или изменить границы.
- Обычное приложение не имеет публичного API для изменения границ уже запущенных чужих задач. Поэтому перетаскивание границ непосредственно на рабочем столе и мгновенное применение размеров без привилегированного доступа здесь не реализованы.
- Обычное приложение не может штатным API скрыть системные заголовки Freeform-окон других приложений. Для этого нужна поддержка со стороны прошивки либо привилегированный системный/root-механизм.
- Если прошивка добавляет собственные отступы, минимальные размеры или заголовки, возможны зазоры. Геометрия теперь рассчитывается по реальному размеру дисплея, но окончательное поведение зависит от оконного менеджера GAC.
